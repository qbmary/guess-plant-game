# Игра «Угадай растение»

## Описание
Два игрока загадывают растение, после чего задают друг другу вопросы, чтобы угадать загаданное. Побеждает тот, кто первым определит растение противника

Особенности:
- Вопросы помогают отсеивать лишние варианты
- Простой и понятный интерфейс

## Технологии
- HTML5
- CSS3

## Запуск
1. Скачайте или склонируйте репозиторий
2. Откройте файл `index.html` в браузере (рекомендуется использовать **Live Server** в VS Code)
3. Играйте!

## Как играть
- Первый игрок загадывает растение
- Второй игрок задаёт вопросы («Это дневное растение?», «Оно атакует?» и т.д.)
- После каждого ответа отсеиваются неподходящие варианты
- Цель - угадать растение соперника
